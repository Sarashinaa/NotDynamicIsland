Dokumen Arsitektur & Produk

Sistem Hamparan Desktop Interaktif Berkinerja Tinggi

Pengembangan sistem dynamic island untuk Windows 11 yang dirancang dari nol untuk mencapai efisiensi ekstrem. Proyek ini membuang seluruh kelemahan teknologi berbasis web (Electron/Tauri) dan mengadopsi pendekatan 100% kode asli (native) untuk menjaga RAM di bawah 30 MB dan penggunaan CPU mendekati 0% saat diam.

< 30MB RAM

Jejak memori sangat ringan dengan alokator khusus mimalloc dan software rendering.

0% Idle CPU

Arsitektur event-driven sejati. Aplikasi tertidur lelap tanpa siklus rendering saat tidak ada animasi.

Prinsip Desain Inti (The 4 Pillars)

Arsitektur ini menduplikasi dan menyempurnakan keunggulan efisiensi, memecahkan masalah keamanan dan beban memori.

Native Code (Tanpa Web Engine)

Ditulis menggunakan bahasa tingkat sistem (Rust). Kompilasi langsung menjadi biner mesin. Menghilangkan sama sekali keberadaan mesin peramban web di latar belakang yang rakus memori.

Draws Only When Moving

Sistem menggunakan Software Renderer berbasis CPU (bukan memuat driver GPU berukuran besar). Hanya menyajikan ulang layar saat elemen bergerak. Saat hamparan diam, eksekusi lingkaran peristiwa dihentikan total (ControlFlow::Wait).

Waits Instead of Checking

Mengharamkan polling. Terintegrasi dengan OS Windows lewat sinyal asinkron. Memantau volume melalui Core Audio API (WASAPI) dan media melalui GSMTC. Aplikasi bereaksi hanya jika Windows mengirimkan sinyal.

Files Stay Where They Are (Zero-Copy)

Modul File Shelf mengadopsi filosofi Zero-Copy. Saat di-drag & drop, sistem hanya mencatat referensi string (PathBuf) dan mengekstrak ikon lewat SHGetFileInfoW tanpa menyalin isi berkas ke memori aplikasi. Bebaskan ikon (DestroyIcon) saat selesai.

Lingkup MVP (Minimum Viable Product)

Media Controller

Sinkronisasi judul, artis, dan durasi secara real-time dari Spotify/YouTube tanpa window aktif.

System Overlays

Notifikasi halus saat terjadi perubahan volume, kecerahan layar, status Caps Lock, dan baterai/charger dicolok.

File Shelf

Kemampuan seret dan letakkan (Drag & Drop) untuk menyimpan file sementara di area hamparan.

Idle Mascot

Menyusut menjadi titik / jam kecil / maskot saat tidak ada aktivitas sistem, menyembunyikan diri tanpa distorsi.

Pedoman UI/UX & Fisika Gerak

  • 1. Animasi Pegas (Mass-Spring-Damper) Alih-alih transisi CSS linear/kubik, animasi merespons dengan kurva kinetik spring(bounce). Memiliki bobot massa, kekakuan, dan redaman. Menghindari osilasi berlebih namun melampaui batas dengan elegan sebelum berhenti presisi.
  • 2. Hit-Testing & Penembusan Klik (Passthrough) Saat idle (menyusut), area transparan jendela harus menembuskan klik tetikus ke desktop atau aplikasi di belakangnya (mereturn HTTRANSPARENT lewat interupsi WM_NCHITTEST). Saat berinteraksi dengan tombol hamparan, rutekan klik ke HTCLIENT.
  • 3. Estetika Layer & Windows DWM Gunakan style jendela WS_EX_TOPMOST | WS_EX_LAYERED | WS_EX_TOOLWINDOW agar tidak muncul di Taskbar/Alt-Tab dan selalu di atas. Gunakan SetWindowCompositionAttribute untuk mencuri efek Blur Behind (Mica/Acrylic) bawaan OS tanpa merender blur di CPU secara manual.

WGPU / DirectX (GPU Accel) 70MB - 135MB Tinggi (Memuat Driver GPU) Ditolak

Kerangka Kerja UI

Disarankan menggunakan Slint UI. Menggunakan arsitektur retained-mode, sangat ringan, dan dikompilasi langsung ke biner Rust. Penyangga piksel (dirty-region tracking) menghemat siklus CPU.

Alokator Memori

Implementasi mimalloc dari Microsoft Research. Menggantikan alokator standar untuk membasmi fragmentasi memori, menangani alokasi string UI dinamis dengan kecepatan tinggi tanpa jejak RAM membengkak seiring waktu.

Ide Berkinerja Lanjutan: Trik Kernel EcoQoS

Agar keberadaan aplikasi tidak disadari oleh sistem manajemen daya (baterai) laptop, arsitektur memaksakan 3 modifikasi tingkat rendah Windows:

1. Penguncian Utas ke Inti Efisiensi (E-Cores)

SetProcessInformation

Lewat properti PROCESS_POWER_THROTTLING_EXECUTION_SPEED, kernel diinstruksikan untuk selalu menjadwalkan komputasi aplikasi ke dalam Efficiency Cores CPU, dengan tegangan voltase terendah.

2. Mitigasi Resolusi Pewaktu

Ignore Timer Resolution

Banyak UI menaikkan *timer resolution* sistem dari 15.6ms ke 1ms untuk animasi. Hamparan ini harus menerapkan atribut PROCESS_POWER_THROTTLING_IGNORE_TIMER_RESOLUTION agar Windows bisa mengelompokkan interupsi dan memasuki mode pemadaman terdalam (Deep C-States).

3. Idle Trimming (Sinkronisasi Memori)

Brutal Force Memory Release

Ketika animasi selesai dan modul idle, sistem memanggil SetProcessWorkingSetSizeEx dengan parameter maksimal dan minimal diset ke -1. Dikombinasikan dengan flag QUOTA_LIMITS_HARDWS_MIN_ENABLE, sistem operasi akan dipaksa menyita page cache aplikasi ini dan memindahkannya ke Pagefile virtual, mereset konsumsi RAM hanya menjadi ~1MB hingga 5MB residu.
